Reading this. The null centre is where a no-signal result actually sits for this data, which need not be 0.500. An observed AUROC only counts as signal if it falls outside the null interval and the confounders do not. If the per-family AUROCs sit at chance while the pooled value does not, the metric is separating receptor families rather than identifying pairs.
